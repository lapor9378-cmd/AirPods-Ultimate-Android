# AirPods Ultimate Android

Aplicación Android en Kotlin para diagnóstico y herramientas de audio Bluetooth.

## Estado

Proyecto en inicialización. Las funciones se validarán en dispositivos reales antes de marcarlas como compatibles.

## Dispositivo objetivo inicial

- TECNO Pova 4
- Android 12

## Principios

- No prometer acceso a protocolos privados de Apple.
- Informar claramente cuando una función no esté disponible.
- Priorizar controles multimedia, diagnóstico Bluetooth y procesamiento de audio local.
